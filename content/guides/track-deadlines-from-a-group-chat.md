Course group chats are where deadlines get announced, changed and buried. One message says the lab report is due Friday, forty messages later someone says the prof moved it, and by the weekend nobody is sure which day is right. This guide shows how to turn that chat into one list you can trust.

## Send the chat, not a summary

Open a private chat with the Settle bot on Telegram. Then forward the messages that matter, paste the text, or send a screenshot of the chat. You do not need to clean it up first. Settle reads Singlish, filler words and half sentences, so "prof say extend to nxt fri liao" is understood as a deadline change.

Settle is made for a private chat with you. It does not go through your group chats, and it only sees what you send it.

## What Settle does with it

Each message is read together with the tasks you already have. That is what makes the difference between a note app and a task list:

- A new deadline becomes a new task.
- A changed deadline moves the task you already have, instead of creating a duplicate.
- "Submitted liao" marks the task as done.
- Chit chat, lunch plans and memes are ignored.

If Settle is not sure which task you mean, it asks you with a Yes or No button instead of guessing. If you answer a question like "which date next week?" with a single word such as "tues", it understands the answer, because it remembers the last few messages of the conversation for ten minutes.

## Dates in Singapore time

Words like "tmr", "this Fri" and "next Fri" are worked out in Singapore time. If a message gives a day but no time, Settle sets the deadline for 23:59 that day. If a task already has a time and a message only changes the day, the time stays the same.

## Check why a deadline moved

Every change keeps the exact words that caused it. On the dashboard, open a task to see its history: the old date, the new date and the quote from the chat. If you are ever unsure, you can also ask the bot why it changed something, and it will answer in a sentence or two.

## See what is due

Send /tasks in the bot for a short list, or open the dashboard. Tasks are grouped into Overdue, Today, This week and Later, so the next thing to do is at the top. You log in with Telegram, so there is no password to remember.

## Be sensible about it

Settle is software and it can misread a message. Dates that matter, like a submission deadline, are worth a quick check against the official course page. The quote saved next to each change makes that check fast.

Forwarding chat messages is free and has no monthly limit, though there is a daily cap on how much you can send to keep the service fair.
